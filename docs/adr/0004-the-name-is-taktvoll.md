# The name is Taktvoll, and magenta is its accent

"DanceCalendar" described the product but named nothing anyone would say aloud, and the masthead's subline tied it to Kassel and Göttingen. The product is now called **Taktvoll** ("in time with the beat", read as a full calendar in the scene's rhythm), with the claim "wo heute getanzt wird" / "where to dance tonight". Neither the name nor the claim names a place, so the calendar can grow beyond the region without another rename; the legal pages and the page at /ueber still say where it runs today. The mark is the word's last two letters drawn as a final barline, a thin ink bar and a thick magenta bar, which also stands alone as favicon and bot avatar. Magenta (#d6006d) replaces the teal accent everywhere, so the brand colour and the accent are one. The cost: the bot handle @DanceCalBot, the repository, the worker and the D1 database keep the old name until someone renames them (a new Telegram handle and WhatsApp display name need the maintainer's accounts), subscribed iCal feeds show the new calendar name, and more magenta competes a little more with the Flyers, so it stays off page surfaces and Flyer frames.
