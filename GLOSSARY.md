# DanceCalendar

A shared calendar for the partner-dance community around Kassel and Göttingen, where organizers post their events and dancers browse and filter them.

## Language

### People

**Organizer**:
An individual person registered to post Events.
_Avoid_: Host, promoter, school (a school is not an Organizer; its people are)

**Dancer**:
Anyone who looks at the calendar; needs no registration.
_Avoid_: User, visitor, attendee

**Display name**:
The name an Organizer's Events are shown under; may be a brand (e.g. "Salsa Kassel") and may be shared by several Organizers.
_Avoid_: Organization, school name

**Admin**:
The person who approves Organizer applications, reviews Tips, and can edit or remove any Event.
_Avoid_: Moderator, operator

### Events

**Event**:
One dated occurrence with a start time and a place, posted by an Organizer.
_Avoid_: Listing, entry, date

**Party**:
An Event for social dancing.
_Avoid_: Social, night

**Workshop**:
An Event where dancing is taught.
_Avoid_: Class, lesson

**Festival**:
A multi-day Event combining Workshops and Parties.
_Avoid_: Weekender, congress

**Series**:
A set of Events that repeat on a schedule (e.g. "every Friday").
_Avoid_: Recurrence, repeating event

**Intro class**:
A short class at the start of a Party, open to everyone; part of the Party, not an Event of its own.
_Avoid_: Taster class, Schnupperkurs, open class, warm-up

**Course**:
A Series of Workshops that Dancers must register for in advance.
_Avoid_: Class series, lesson block

**Venue**:
A named place with a known location where Events happen; shared across Events so each place exists once.
_Avoid_: Location, address, club

### Submissions

**Flyer**:
The image or text already shared on WhatsApp to announce an Event; the raw input from which Events are created.
_Avoid_: Poster, announcement

**Tip**:
A Flyer sent in by a Dancer rather than an Organizer; its Events appear only after the Admin approves them.
_Avoid_: Suggestion, report
