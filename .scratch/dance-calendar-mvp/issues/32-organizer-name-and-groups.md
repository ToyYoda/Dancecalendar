# Organizer name instead of a Display name, and Organizer groups

Type: grilling
Labels: wayfinder:grilling

## Question

From the Admin's review of the onboarding (2026-11-01): an Organizer should have only their own name, not an alias (the Display name). What the Display name does today – a shared public name like „Salsa Kassel“ that several people can post under – should become an **Organizer group** concept instead.

Decide:

- Which name an Organizer gives (first and last name? only first name?) and what of it is public on their Events.
- What an Organizer group is: who creates it, how Organizers join or leave (today: typing an existing Display name joins it, flagged to the Admin), whether an Organizer can be in several groups, and how an Event names its group vs. its Organizer.
- What happens to existing Display names and Events (migration).
- Knock-on changes: the application form ([Organizer application form](12-organizer-application.md), [Organizer application](20-organizer-application.md)), Admin tools („Organizer zuweisen“), the Dancer overview, the privacy policy (a real name in public is new personal data) and `GLOSSARY.md` (Display name, a new term for the group).

The outcome is the decided model plus the build ticket(s) that apply it.
