# TypeScript on Cloudflare Workers, not Python on a server

The whole app (WhatsApp webhook, extraction queue, cron jobs, and all pages) is one TypeScript Worker on Cloudflare's free plan, using D1, R2 and Queues pinned to the EU. We chose this over Python, the maintainer's only (slight) language, for two reasons. Python on Workers runs via Pyodide, and its docs don't confirm the `anthropic` SDK, queue consumers, or a fit within the free plan's 10 ms CPU limit. Python FastAPI on a Hetzner server would have cost about €6–10/month after Hetzner's 2026 price rises, plus server upkeep for a single maintainer. The cost of this choice: vendor lock-in to the Workers runtime, and Cloudflare as one more US processor (DPA via the EU-US Data Privacy Framework). Don't port the app to Python or a VPS just because Python is the maintainer's language: the code is written with an agent's help either way, and zero running cost and zero ops were the deciding constraints.
