# Organizers post under their own name, with no Display name or Organizer group

An Organizer used to choose a Display name, which could be a brand like „Salsa Kassel“ and could be shared: typing an existing one joined it, flagged to the Admin. The Admin's review of the onboarding found that an alias hides who actually posts, and the follow-up idea, Organizer groups, would have added membership, joining and leaving for a calendar with a handful of Organizers. We decided (2026-11-25) that each Organizer has only their own name, one free-text field shown on their Events exactly as entered, and nobody can post under someone else's name. The private first name goes as well, since the name now serves both purposes. The cost: a dance school or a team can't appear under one shared brand, a real name is now public personal data (named in the privacy policy), and existing Organizers whose Display name is a brand keep it until the Admin asks them for their own name; nothing is merged or renamed automatically. Don't reintroduce shared names or groups without reopening this decision.
