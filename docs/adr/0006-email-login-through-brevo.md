# Organizers can log in with a link by email, sent through Brevo

Organizers could log in at /veranstalter only with Telegram or Google, so someone with neither had no way in, and the code already noted that email login waited for a domain to send from. With stepdate.de there is one. We decided (2026-11-25) to add a login by email link: the Organizer enters an address, gets a link that works once and for 15 minutes, and opening it shows one „Jetzt anmelden“ button, because mail scanners open links by themselves and only the button's POST uses the link up. There are no passwords. An address logs in as the account it was first added to (a Telegram chat or Google login, if the browser was logged in), else as a Google login with the same verified address, else as a new „web:“ account, which joins the Telegram chat like a Google-only account does. Links are capped at 3 per address per 15 minutes and 250 a day, without telling the browser, so the page reveals nothing about an address.

The mail goes through Brevo's transactional HTTP API (free plan, 300 emails a day, company and servers in the EU), not Cloudflare Email: on the Workers Free plan Cloudflare sends only to verified destination addresses, and reaching any address would need Workers Paid at $5 a month. The Admin's daily email uses the same helper (src/mail.ts), with the old send_email binding as fallback. The cost: a second outside processor with its own account, DPA and DNS records (SPF, DKIM, DMARC on stepdate.de), a third-party API key as a Worker secret, a hard ceiling of 300 emails a day for both login links and the Admin's email, and whoever can read an Organizer's inbox can log in as them. Revisit if the cap is ever hit or the project moves to Workers Paid anyway.
